# 独知 DuZhi

隐私增强、无广告的知乎第三方客户端。Android 为主，并提供实验性桌面版：去广告、去推广软文、去带货、去盐选专栏，支持本地推荐算法、关键词 / 用户 / 话题屏蔽，交互尽量贴近知乎官方 App。

- **来源与许可**：派生自 [Zhihu++](https://github.com/zly2006/zhihu-plus-plus)（作者 zly2006），基于其 `master` 的 `eb9d9a7a`（2026-10-11）由 in-Solitude 修改并独立维护。整个项目沿用 AGPL-3.0（仅第 3 版），源文件中的原作者版权声明均保留。
- **开发方式**：需求和验收由 in-Solitude 负责，代码由 [Claude Code](https://claude.com/claude-code) 编写。
- **与知乎的关系**：本应用不由知乎官方开发或运营，也不受知乎官方承认或支持。

## 相对 Zhihu++ 的改动

### 新功能：隐藏知乎黑名单用户

你在知乎账号里拉黑的人，在独知里也看不到。设置 → 内容过滤 → “隐藏知乎黑名单用户”，默认开启。

| 位置 | 效果 |
| --- | --- |
| 问题下的回答 | 直接隐藏 |
| 搜索结果 | 直接隐藏 |
| 评论 | 折叠成一行“已屏蔽 · 规则：知乎黑名单用户「xxx」，点击显示” |
| 首页推荐 | 不处理（知乎自己已经过滤） |

在 App 里拉黑或取消拉黑某人会立即生效；切换账号后自动按新账号重新判断。

### 本地屏蔽（对应网页版插件的本地黑名单）

上游原有的“屏蔽用户”只管首页推荐，现在扩展成和网页版插件一样的本地黑名单：只存在本机、按用户 ID 匹配、不占知乎黑名单名额。

- **范围**：首页、关注、问题下的回答、搜索、话题、收藏夹、别人主页的动态里，被屏蔽者的内容折叠成一行“已屏蔽 · 规则：本地屏蔽用户「xxx」”，点击仍能打开；评论折叠成同样一行，点击展开。被屏蔽者自己的主页不处理
- **入口**：用户主页“本地屏蔽”按钮（原“屏蔽推荐”）、评论右下角 ⋮ 菜单、首页 / 关注 / 搜索结果卡片菜单“屏蔽用户”
- **批量添加**：设置 → 内容过滤 → 屏蔽列表 → 屏蔽用户 → +，可一次粘贴多个主页链接、url_token 或用户 ID；网页版插件“编辑本地黑名单”里 `|` 分隔的名单可以直接粘贴，查不到的会留在输入框里
- **开关**：设置里的“启用用户屏蔽”现在对上述所有位置生效

### 交互调整（向官方 App 看齐）

- **首页启动**：打开应用先显示上次的推荐，不再空等网络；新推荐在后台加载好后放到上面，顶部出现“有新推荐”，点一下回到顶部
- **用户主页**：左上角加了返回按钮
- **信息流**：点作者头像或名字进入作者主页（上游这里点了没反应）
- **关注页**：常看作者头像栏和“推荐 / 最新”两个小按钮放在顶部，切换时不动、往上刷会收起；默认进入“最新”；不再左右滑动切换
- **底栏**：默认去掉“日报”，仍可在外观设置里加回来
- **“下一个回答”按钮**：图标换成向下的双箭头；所有悬浮按钮吸附时离屏幕边留出 12dp
- **首页“+”按钮**：直接发想法（上游菜单里的“提问题”“写回答”只会提示“正在施工”）
- **热榜**：左侧显示排名，前三名高亮
- **数字**：回答底栏和问题页的赞同、评论、浏览、关注、回答数显示成“1.2 万”这种写法
- **其他**：长按信息流卡片打开“更多”菜单；多图查看时顶部显示页码；搜索历史可单条删除；回到首页时通知角标会更新

### 加载失败与操作反馈

- **回答 / 文章页**：加载时显示转圈，失败时显示原因和“重试”（上游是空白页或一行“荒原”）
- **信息流**：加载失败后底部显示“加载失败：…，点击重试”（上游会一直转圈，也不再往下加载）
- **评论**：发送或点赞失败会弹出提示，输入的内容保留（上游发送按钮会一直转圈、没有提示）；评论加载失败也能重试
- **屏蔽作者**：在首页、关注、搜索的卡片菜单里屏蔽后，已加载的条目原地折叠，不再整页刷新丢掉位置

### 和原项目断开联系

- **不再连接原作者的服务器**：删除了匿名使用统计（遥测）、首页在线通知、崩溃上报，以及依赖原作者服务器的“标记疑似 AIGC”（含阅读进度上报和积分）。原项目的 AIGC 投票服务端代码 `aigc-vote-server` 也一并删除
- **不再展示原作者的内容**：删除了首页的原作者想法 / 投票公告卡片，原作者账号的“知乎++ 作者”徽章，以及在原作者回答和想法下评论时弹出的“评论区使用须知”
- **检查更新**：改为检查本仓库的 GitHub Releases，不再使用原作者的镜像；“国内网盘加速下载”入口随之去掉
- **链接**：项目地址、开源协议、问题反馈、导出文件页脚都指向本仓库；去掉原作者的 Discord / Telegram 群组
- **名称与身份**：应用改名“独知”，包名改为 `io.github.insolitude.duzhi`；桌面版和 macOS 版的名称、安装包标识也已更换
- **登录前确认**：去掉了“同意遥测”那一步

## 功能

- 登录与账号
  - 支持手机验证码登录
  - 支持通过扫码在电脑端登录
  - 支持手动设置 Cookie 登录
- 信息流与推荐
  - 首页推荐支持 Web / 安卓 / 本地 / 混合模式
  - 支持切换 **登录状态 / 非登录状态** 下的推荐，防止信息茧房
  - 支持关注页（推荐/动态，可显示动态来源说明）、热榜、知乎日报、搜索（含热搜、历史、排序/类型/时间筛选）
  - 支持智能内容过滤、质量过滤、反向屏蔽、过滤统计与屏蔽记录
  - **支持屏蔽知乎盐选付费内容**
- 内容浏览
  - 阅读回答
  - 阅读文章
  - 浏览问题详情页（排序、关注、日志、分享、评论）
  - 浏览想法（Pin）详情页（点赞、评论、分享、话题、投票）
  - 浏览收藏夹及收藏夹内容
  - 在用户主页内搜索 TA 的创作
  - 历史记录（在线历史 + 本地历史，支持删除）
  - 展示知乎官方认证徽章
  - 应用内播放知乎视频
- 阅读
  - 朗读内容（听文章 / 听回答）
  - 回答页长按保存图片 **无水印**
  - 回答切换手势（上下/左右切换）与”下一个回答”按钮
  - 沉浸式阅读，可隐藏回答区干扰元素
  - AI 总结内容
  - **导出内容**（PDF / 图片 / Markdown / HTML）
  - **支持导出整个收藏夹**
  - 内容划线高亮
  - 图片查看器支持动图（GIF）与多图滑动切换
  - 数学公式渲染（LaTeX，字体动态下载）
  - 支持调节正文段间距
  - 可拖动滚动条、上划/下划自动隐藏/显示操作按钮
- 内容创作
  - Android 端支持写回答、编辑已有回答、保存草稿和发布回答
  - 写回答支持 Markdown 编辑、预览和插入图片
- 社区互动
  - 支持查看个人主页（含关注订阅板块）、关注/拉黑用户、本地屏蔽
  - 支持查看回答赞同者列表，以及关注的人赞同
  - 评论区（含子评论、回复、点赞、按时间排序）
  - 通知（支持分类、红点设置、全部标记已读、自动标记已读与通知筛选）
  - 表情包
    - 经典表情`[惊喜]` <img src="misc/emojis/emoji_1114211280118018048.png" height="18" style="diSplay:inline"> 强势回归！
- 屏蔽系统
  - 屏蔽词（支持正则表达式）
  - NLP 屏蔽词（基于 LLM embedding 和向量相似度匹配，仅 full 版本可用）
  - 屏蔽用户（含评论、问题回答等场景）
  - 隐藏知乎账号黑名单里的用户（问题回答、搜索结果；评论折叠为可点开的占位），可在设置中关闭
  - 屏蔽话题（含想法流）
  - **导出屏蔽词** & **导入屏蔽词**（支持跨设备迁移）
  - 屏蔽历史记录
- 其他
  - 基于 Kotlin Multiplatform 共享核心代码，支持 Android 与实验性桌面端
  - 支持 zse96 v2 签名算法（可以调用 99% 的网页端 API）
  - 支持模拟安卓端 API 调用
  - 支持 Deep Link 与剪贴板链接识别跳转
  - 支持二维码扫码结果展示和复制，可用于提取网址、Wi-Fi 密码等信息
  - 主界面支持横滑切换标签页
  - 防沉迷提醒
  - 支持自定义初始页面
  - 双击操作快速 **点赞** 或 **打开评论区**
  - 点击底部导航栏回到顶部/刷新
